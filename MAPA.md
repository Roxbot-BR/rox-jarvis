# MAPA — Índice do Cérebro Compartilhado

Use este arquivo como ponto de entrada. Consulte apenas as áreas relevantes para a tarefa em andamento.

| Área | Finalidade | Conteúdo adequado |
|---|---|---|
| `identidade/` | Identidade e princípios | Missão, tom, limites, critérios de qualidade |
| `arquitetura/` | Desenho técnico | Componentes, fluxos, decisões e fronteiras de isolamento |
| `agentes/` | Especialização de agentes | Papéis, responsabilidades, interfaces e limites |
| `skills/` | Procedimentos reutilizáveis | Objetivo, pré-requisitos, passos, validação e recuperação |
| `integracoes/` | Serviços externos | Contratos, OAuth, escopos, erros e testes, nunca credenciais |
| `operacao/` | Operação e suporte | Runbooks, monitoramento, backup, incidentes |
| `projetos/` | Contexto de projetos | Objetivo, estado, decisões, riscos e próximos passos |
| `templates/` | Modelos | Registro de decisão, skill, incidente e projeto |
| `memoria/` | Aprendizado compartilhável | Decisões duráveis e lições generalizáveis, sem dados pessoais |

## Fluxo recomendado de consulta

1. Ler este mapa.
2. Ler a identidade e as regras de segurança pertinentes.
3. Consultar o arquivo de arquitetura ou projeto relevante.
4. Consultar skills/runbooks relacionados.
5. Após concluir, propor uma atualização apenas quando houver aprendizado durável comprovado.

## Classificação do conhecimento

- **VALIDADO:** testado ou confirmado por fonte confiável, com evidência indicada.
- **PROPOSTA:** recomendação ainda não testada.
- **PENDENTE:** informação incompleta que precisa ser confirmada.
- **OBSOLETO:** preservado para histórico, não deve orientar novas ações.

Não misture estado proposto com estado implementado.
