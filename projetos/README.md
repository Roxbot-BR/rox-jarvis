# Projetos

Cada projeto deve ter um arquivo dedicado, por exemplo `nome-do-projeto/README.md`, com:

- Objetivo e escopo.
- Estado atual confirmado.
- Componentes e ambiente relevantes.
- Decisões tomadas e respectivas razões.
- O que foi testado, resultados e evidências.
- Riscos, limitações e dependências.
- Próximas ações priorizadas.
- Histórico de mudanças e data de revisão.

Separar claramente: **concluído**, **em andamento**, **planejado** e **bloqueado**. Não registrar senhas, tokens, dados pessoais ou arquivos de produção.
