# Skills — Catálogo e padrão

Uma skill é um procedimento reutilizável. Ela não cria, por si só, ferramentas, permissões, conectividade ou controle de computador.

## Estrutura recomendada para cada skill

1. **Objetivo**
2. **Estado:** proposta, validada, obsoleta
3. **Pré-requisitos**
4. **Permissões e limites**
5. **Entradas e saídas**
6. **Procedimento numerado**
7. **Validação do resultado**
8. **Tratamento de erros e recuperação**
9. **Impactos e ações que exigem confirmação**
10. **Testes, evidências, versão e última revisão**

## Critérios mínimos de validação

- Reproduzir o procedimento num ambiente autorizado.
- Confirmar resultado observável, não somente saída textual.
- Testar pelo menos um cenário de erro.
- Remover credenciais e dados pessoais de exemplos/logs.
- Informar claramente as versões e pré-condições conhecidas.

Não marcar como validada uma skill que foi apenas escrita ou revisada teoricamente.
