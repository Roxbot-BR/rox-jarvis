# Memória Compartilhável

Este diretório é para decisões e aprendizados generalizáveis aprovados para compartilhamento — não é o armazenamento da memória privada de cada usuário.

## Pode entrar

- Decisões técnicas duráveis.
- Procedimentos comprovados.
- Lições aprendidas sem identificação pessoal.
- Referências para documentação pública ou artefatos compartilhados autorizados.

## Não pode entrar

- Conversas privadas ou transcrições brutas.
- Credenciais, tokens, cookies ou chaves.
- Dados pessoais, financeiros, de saúde ou identificadores de usuários.
- Dumps de banco de dados e logs com informação sensível.

## Registro recomendado

Cada nota deve conter contexto, aprendizado, estado de validação, fonte/evidência e data de revisão. Se uma informação estiver relacionada a um usuário, empresa ou projeto confidencial, confirme a autorização e minimize os detalhes antes de compartilhá-la.
